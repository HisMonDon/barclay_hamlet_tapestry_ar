About this view

The animation is rendered live by the tapestry engine and laid onto a virtual board, with the four tracking markers where they sit on the real one. No camera is used.

Camera

Phone apps such as Camo, DroidCam, Phone Link or Continuity Camera show up here as webcams.

  1. Put the phone on the same Wi-Fi as this computer.
  2. Scan the code with the phone’s camera and open the link.
  3. The page warns about its certificate once. Choose Advanced → Proceed (Android) or Show Details → visit this website (iPhone).
  4. Tap Start camera on the phone and allow access.

If Windows asks whether Python may use the network, allow it on private networks.

Use the MJPEG or RTSP address from an IP camera app, for example IP Webcam (http://phone-ip:8080/video) or DroidCam (http://phone-ip:4747/video). A number such as 0 opens that camera through OpenCV, as app.py --camera does.

Placing the tapestry

  • Print markers.pdf at 100% / Actual size and check the 100 mm scale bar.
  • Place markers 0–3 clockwise from the top-left, upright, inner corners facing the drawing, 8 mm beyond its edges.
  • Mount the camera above the board, looking down, with the whole board filling about two-thirds of the picture.
  • Light the board evenly and avoid glare on the markers. At least 3 must be visible to lock on.
  • The show waits for the first lock. If markers are covered later, the last good position is held.
